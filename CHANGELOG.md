# Changelog

All notable changes to this package. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and versions follow [Semantic Versioning](https://semver.org/): before 1.0 a minor release may break the API,
after 1.0 only a major one may. Each release names the cel-go and cel-spec versions it tracks and its
conformance numbers (`python3 tools/dashboard/dashboard.py --run`).

## [Unreleased]

First release, for PRBar. Tracks cel-go v0.32.0 and cel-spec v0.25.3.

### Added

- `CEL`: parser, macros, unparser and debug printer matching cel-go byte for byte; type checker; interpreter
  with cel-go's attribute resolution, error messages and runtime cost; standard library; static cost
  estimation and cost, time, size and cancellation limits; partial evaluation with unknowns, residual
  expressions, state tracking and exhaustive evaluation; constant folding and inlining optimizers; DocC
  catalog.
- `CELExtensions`: cel-go's extension libraries (strings, lists, math, sets, encoders, network, regex,
  bindings, two-variable comprehensions, formatting) with their cost estimators.
- `CELProtobuf` and `protoc-gen-cel-swift`: protobuf messages, enums, extensions and well-known types for
  types generated by the plugin.
- `CELPolicy`: cel-go's YAML policy format, environment configs, policy compiler and composer.
- `CELTest` and `cel-swift policy test`: cel-go's `tests.yaml` suites.
- `cel-swift` command line tool: `eval`, `check`, `parse`, `repl`, `policy test`.

Conformance (cel-spec v0.25.3): 2473 / 2508 checked, 2310 / 2339 parse-only; the remaining tests are the
strong-enum ones cel-go and cel-cpp skip too. Deliberate differences from cel-go are listed in
`docs/divergences.md`.
